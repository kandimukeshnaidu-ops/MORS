# MORS Beta Issue & Feedback Log Template

**Issue Log Format for Weekly Closed Beta Triage**

| Field | Description / Example Values |
|---|---|
| **Issue ID** | `BETA-001`, `BETA-002`, ... |
| **Tester Persona** | Home Cook / Cafe Explorer / Street Foodie / Non-Technical |
| **Screen / Flow** | Quick Log / Diary / Feed / Collections / Settings |
| **Severity** | `P0` (Privacy / Data loss) \| `P1` (Broken core journey) \| `P2` (UX friction) \| `P3` (Feature request) |
| **Frequency** | Once (1 user) \| Repeated (2-4 users) \| Common (>5 users) |
| **Issue Summary** | Plain English description of what happened |
| **Expected Behavior** | What the user expected to happen |
| **Evidence / Logs** | Browser / OS / Error text / Screenshot link |
| **Proposed Solution** | Engineering fix or UX adjustment |
| **Status** | `Open` \| `In Triage` \| `Fixed (PR)` \| `Deferred (Post-Beta)` |
